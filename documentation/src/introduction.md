# EwQwE Identity

**EwQwE** (pronounced /juːˈkwiː/ or *you-kwee*) **Identity** is a set set of software to handle Digital Identity, and more specifically [European Digital Identity (EUDI)](https://digital-strategy.ec.europa.eu/en/policies/eudi-regulation).

In particular, it provides a Credential Verifier server that can be used by websites and applications (a.k.a Relying Parties) that need to perform [EU compliant Age Verification](https://ageverification.dev/av-doc-technical-specification/docs/architecture-and-technical-specifications/#23-user-journey).
